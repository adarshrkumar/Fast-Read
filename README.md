# Fast-Read

A speed reading web application that displays text one word at a time to help you read faster.

## Features

- **Adjustable Speed**: 60-600 words per minute
- **Multiple Input Methods**: Upload `.txt` files or paste text directly
- **Text-to-Speech**: Optional audio playback of words
- **Dark Mode**: System-aware with manual toggle
- **Progress Tracking**: Word count, progress bar, and time remaining
- **State Persistence**: Saves your place, speed settings, and last file to localStorage
- **Start Position**: Begin from the start or from cursor selection

## Usage

1. Upload a text file or paste text into the textarea
2. Click "Start Reading" to prepare the text
3. Adjust speed with the slider
4. Press play to begin speed reading
5. Toggle audio if you want words spoken aloud

## Tech Stack

- HTML/CSS/JavaScript
- Web Speech API for text-to-speech
- LocalStorage for persistence
- Material Icons
- Hosted via GitHub Pages
